v7 skin-lesion classifier

Research demo, not a medical device. Do not use it for diagnosis or any clinical decision. Trained and evaluated on dermoscopic images (HAM10000); phone photos are out of scope.

Serve the release folder and open this page from it, so the model file can be fetched: python -m http.server 8000 in the release root, then http://localhost:8000/web/. Everything runs in your browser; no image leaves it.
