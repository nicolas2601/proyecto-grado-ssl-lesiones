## What it is

{{n_models}} research models, one per arm and pretraining seed: {{a_models}} (A\*, anchored SimSiam adaptation) and {{b_models}} (B\*, the same adaptation plus a tone-consistency term). Each is a DINOv2 ViT-B/14 backbone adapted to dermoscopy with self-supervised learning only, followed by a linear probe that predicts the 7 HAM10000 classes: `akiec`, `bcc`, `bkl`, `df`, `mel`, `nv`, `vasc`.

- **No label ever reached the backbone.** Pretraining is self-supervised on unlabelled images. Labels are used only to fit the probe.
- **Probe:** `StandardScaler` + multinomial `LogisticRegression` (lbfgs, `C=1.0`, `max_iter=2000`, `random_state=42`, no class weights), fitted on the C1 fold-0 train of HAM10000 (8011 images, grouped by `lesion_id`). The release folds the scaler into the linear layer (`W' = W / sigma`, `b' = b - W (mu / sigma)`), so the head is one `Linear(768, 7)` + softmax.
- **Input:** the CLS token after the final LayerNorm (`x_norm_clstoken`) at 224 x 224.

## What changed from v6

The v7 redesign is registered in `docs/28-rediseno-brazo-propuesto-v7.md` §2-§3 (values and sources there, not repeated here): patch embedding and blocks 0-7 frozen, layer-wise learning-rate decay on the trainable blocks, an L2-SP weight anchor and a feature anchor towards public DINOv2, milder hue jitter, and, for B\* only, a real tone-consistency term on the same crop. The confounders of v6 were fixed: validation and selection-holdout ids excluded from the pretraining pool, the same number of steps in both arms, and one code revision per final. The variants were selected on an internal holdout of the train split, never on validation (docs/28 §4).

## Release forms and parity rules

Each model ships as `hf/` (Hugging Face `Dinov2Model` `config.json` + `model.safetensors`, and `head.safetensors` with the fused head, class order and preprocessing) and `onnx/` (end to end, fp32, and fp16 when it passes the rule). Usage: `USO_MODELOS.md`.

Every gate is hard; a model that fails one is not released (`parity.json` in each model folder):

- **Evaluation reproduced exactly:** the head is refit on the features of the evaluation (CUDA, fp16 autocast, the same extraction code), and the refit path and the released fused head give exactly the committed predictions and the `final_eval.json` macro-F1 (tolerance {{json_tol}}).
- **Forms agree:** hub fp32 path, torch, transformers and ONNX within atol {{forms_atol}} with identical argmax on the first 100 val images, and the same val macro-F1.
- **fp16 copy:** published only if its argmax matches torch fp32 on at least {{fp16_agreement}} of val images and |delta macro-F1| <= {{fp16_delta}}; otherwise the release is fp32 only.

## Intended use

Research on self-supervised adaptation for dermoscopy: reproducing the thesis results, feature extraction, and comparison with other methods. **This is not a medical device and must not be used for diagnosis, triage or any clinical decision.** The outputs are probabilities of a research model evaluated on one dataset.

## Limitations

- **Dermoscopy only.** Trained and evaluated on dermoscopic images (HAM10000 for the probe; HAM10000, ISIC 2019 and ISIC 2020 in the pretraining pool). Expect degradation on clinical, phone or webcam photos; this is still to be quantified with PAD-UFES-20 (`docs/29-plan-v7.1.md` §2.6).
- **HAM10000 classes only.** Seven classes; any other lesion is forced into one of them.
- **One distribution.** Validation is a held-out fold of the same dataset (grouped by lesion); there is no external classification test yet.
- **Skin tone.** HAM10000 is mostly light skin (Fitzpatrick I-III); there is no basis for claims on types IV-VI and a performance gap is likely (`docs/07-fiabilidad-y-sesgo.md`, skin-tone section; tone estimation work in `docs/20-validacion-externa-fst-fitzpatrick17k.md`).
- **Calibration.** ECE is reported on validation only; probabilities are not calibrated for other populations.
- **Resolution.** The released weights embed the position grid for 224 x 224 input; other sizes are not supported.
