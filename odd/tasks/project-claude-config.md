# Project .claude/ Configuration

## Objective
Build the project-scoped `.claude/` layer that is currently missing from the
repository: project `CLAUDE.md` (context/roles), `.claude/agents/` (domain
subagents), and `.claude/skills/` (project-specific workflows). Today the
repo only has `odd/tasks/` and `openspec/` for workflow state; there is no
versioned project context for Claude Code sessions or delegated subagents.

## Why
Repo is a graduation thesis project (self-supervised learning for skin
lesion classification) that is actively scaling: CRISP-ML(Q) methodology,
multiple pipeline versions (currently v8), heavy use of ODD/openspec
tracking already. Project knowledge lives scattered across `docs/*.md`;
without a project `CLAUDE.md`, every new session or delegated subagent has
to rediscover context by reading loose docs.

## Scope
- In scope: `CLAUDE.md` at repo root, `.claude/agents/*.md`, `.claude/skills/*`,
  any project-specific context/roles/orchestration docs the user wants folded
  into `.claude/`.
- Out of scope (unless requested): changing the existing `odd/` or
  `openspec/` workflow mechanics themselves.

## Constraints
- Match existing project documentation convention: Spanish, neutral/professional
  register (see `docs/*.md`, `INFORME.md`, `INFORME_ACADEMICO.md`).
- Must not duplicate or contradict the user's global `~/.claude/CLAUDE.md`
  (ODD/SDD orchestrator rules, Gentleman persona, etc.) — project CLAUDE.md
  describes *this project's* domain, architecture, conventions, and state,
  not generic workflow machinery already defined globally.
